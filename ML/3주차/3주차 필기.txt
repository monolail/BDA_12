GA4 : Funnel -> Pathfinder -> Journey

유저가 어디서 많이 이탈하고 있을까?

온보딩 퍼널에서 자주 발견되는 문제
계좌 인증에서 70%이탈 -> 게좌 인증 UX문제
첫 기능 사용까지 오래 걸림 -> 온 보딩 가이드 부족

Pathfinder : 행동 흐름을 통해 원인을 파악하는 단계
유저가 그 다음 행동은 무엇이 였을까/? -> 이탈한 유저가 실제로 어디에 갔는가?

체크 포인트 : 예상과 다른 경로로 이동 / 이탈 직전 행동 / 특정 행동 반복

Journey 전체 흐름 파악

유저가 전체적으로 어떤 경로로 이동하고 있을까?

체크 포인트 : 주요 이동 경로 / 비정상적인 흐름 / 이탈이 발생하는 전체 구조

온보딩 퍼널이란? : 유저가 앱을 설치한 후 실제로 서비스를 사용하기 시작하는 과정을 단계별로 추적 및 분석하는 방법.

Pathfinder와 Journey 차이점:

<Pathfinder>
유저가 특정행동이후 다음에 무슨 행동을 하는지 확인하는 분석
-> 회원 가입 이후 경로 : 좋아하는 브랜드 선택 -> 좋아하는 카테고리 선택 -> 프로필 완료 -> 이탈

<Journey>
유저가 전체행동흐름을 한눈에 보는 분석 유저가 특정 행동까지 도달하는 경로를 파악한다.
-> 구매까지 전체 경로 : 좋아하는 브랜드와 카테고리 선택 -> 프로필 완료 -> 메인 랜딩 -> 아이템 검색 및 구매
