퍼널 분석과 세크멘테이션 분석
[퍼널 -> 패스파인더 -> 저니] -> 세그멘테이션
-> 현황 분석(전체)				-> 쪼개서 분석

세그멘테이션 : 같은 퍼널과 흐름을 다른 유저 그룹으로 쪼개서 비교한다.

- 각각의 과정을 쪼개서 분석이 가능.

퍼널의 문제 -> 이탈 구간 ㅌ탐색
: 유저가 어디서 많이 이탈하는가?

- 전체 퍼널에서 자주 발견되는 문제

퍼널의 목적 : 전환 분석
패스 파인더 목적 : 행동 흐름 분석
저니 목적 : 전체 여정 구조 분석
세그멘텡이션 : 유저 그룹별 행동 차이 분석

메인 퍼널 : 유저가 서비스에 들어온 이후 핵심 비즈니스 목표에 도달하는 과정 ( 총 전환 )

이벤트 세그멘테이션 : 특정 이벤트를 기준으로 유저를 사용자 속성이나 행동 기준으로 나눠서 그룹의 행동 차이를 비교한다.
-> 특정 이벤트(무엇을?)를 기준으로 유저(누구를?)의 행동을 나누고 비교하는 기능

그룹 세분화 
-> 국가별 , 성별, 나이별 등 그룹으로 묶어서 세분화를 진행한다.
