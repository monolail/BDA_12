# BDA 12기 저장소 (BDA_12)

이 저장소는 BDA(Big Data Analysis) 12기 활동을 하며 학습한 내용, 과제 및 공모전 관련 파일들을 보관하고 있습니다.

## 디렉토리 구조

### 1. ML (머신러닝)
* 매주 진행된 머신러닝 학습 자료 및 과제가 포함되어 있습니다.
* 데이터 분석, 모델 평가, Amplitude 활용 기획안 등의 문서와 실습 과제로 구성되어 있습니다.

### 2. SQL
* 1주차부터 10주차까지 진행된 SQL 실습 및 복습 과제가 포함되어 있습니다.
* 기본 테이블 설정부터 시작하여 문자열/날짜 함수 활용, 쿼리 아키텍처, JSON 데이터 다루기 등 주차별 SQL 쿼리문(.sql)과 관련 학습 자료가 정리되어 있습니다.

### 3. 제5회 BDAI 채용 연계 데이터 분석 공모전
* 공모전 참여를 위해 작성된 분석 리포트, 기획안, 발표 자료 등이 포함되어 있습니다.
* 모델 평가 및 전력/설비 분석 등과 관련된 이미지 및 노트북 파일이 포함되어 있습니다. 
* (참고: 원본 대용량 데이터 파일인 .zip 및 .csv 파일 등은 용량 문제로 업로드에서 제외되었습니다.)

## 유의사항

* GitHub의 업로드 용량 제한으로 인해 대용량 데이터 파일(.zip, .csv 등)은 `.gitignore` 처리가 되어 저장소에 포함되어 있지 않습니다.
