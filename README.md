# BDA 12기 활동 저장소 (BDA_12)

이 저장소는 **2026년 3월 1일부터 2026년 7월 15일까지** 진행된 BDA(Big Data Analysis) 12기 정규 활동을 통해 학습한 내용, 주차별 실습 과제 및 데이터 분석 공모전 결과물들을 체계적으로 보관하고 있습니다.

## 주요 활동 내용 및 디렉토리 구조

### 1. ML (머신러닝)
본 디렉토리는 머신러닝의 이론적 배경과 실제 데이터를 활용한 실습 내용을 담고 있습니다.
* **주차별 실습 과제**: 매주 진행된 머신러닝 학습 모델 구축 및 성능 평가 실습 코드
* **데이터 분석 및 모델 평가**: 주어진 데이터셋을 활용하여 다양한 머신러닝 알고리즘을 적용하고 결과를 분석한 문서 파일
* **Amplitude 활용 기획안**: 프로덕트 분석 도구인 Amplitude를 활용하여 실제 서비스의 지표를 정의하고 가설을 검증하는 데이터 분석 기획안 (PDF 문서 포함)

### 2. SQL
데이터베이스 및 SQL 문법을 기초부터 심화 단계까지 주차별로 학습한 내용입니다. (1주차 ~ 10주차)
* **기초 문법 및 테이블 설정**: 1주차 기본 세팅 및 데이터베이스 스키마 구성 실습
* **데이터 가공 및 집계**: 문자열, 날짜 함수 및 그룹화(GROUP BY)를 활용한 쿼리 작성 실습
* **고급 쿼리 아키텍처**: JSON 형태의 데이터 다루기, 논리 구조 작성(Logic Engineering) 및 복잡한 서브쿼리 활용 실습
* **주차별 산출물**: 매 주차 진행된 복습 과제 및 필수 과제의 SQL 쿼리문(.sql) 파일과 관련 이론 정리 자료

### 3. 제5회 BDAI 채용 연계 데이터 분석 공모전
BDAI에서 주최한 데이터 분석 공모전에 참가하여 진행한 실전 분석 프로젝트 산출물입니다.
* **분석 기획 및 리포트**: 1인 팀으로 참여하여 작성한 최종 데이터 분석 리포트, 참가 신청서 및 기획안 문서 (.docx, .pdf)
* **코드 및 모델링**: 전력 및 장비 운영 데이터를 활용한 탐색적 데이터 분석(EDA)과 예측 모델 구축 과정이 담긴 Jupyter Notebook(.ipynb) 파일
* **분석 결과 시각화**: 주요 장비 분석 결과, 시간대별 평균 활성 전력량, 모델 성능 평가 및 변수 중요도 분석 등의 결과를 정리한 시각화 이미지 파일

## 참고 및 유의사항

* **용량 제한 안내**: GitHub의 단일 파일 업로드 용량 제한(최대 100MB) 규정에 따라, 모델링 및 분석에 사용된 원본 대용량 데이터 원본(약 1.5GB 상당의 .zip 및 .csv 파일 등)은 원격 저장소에 포함되지 않도록 제외(.gitignore) 처리되었습니다.
* **주요 사용 환경**: 본 저장소의 실습 코드는 주로 Python 기반의 Jupyter Notebook 환경 및 SQL 환경에서 작성 및 테스트되었으며, 기획안 및 최종 결과 리포트는 텍스트 및 문서 편집 도구를 활용하여 작성되었습니다.
